## Evaluación del curso

| Categoría | Porcentaje |
|---|---|
| Participación | 25% |
| Deberes | 25% |
| Evaluaciones y certificaciones | 25% |
| Proyecto Final | 25% |

### Descripción de las categorías de evaluación

**Participación.** Se calificará la participación activa demostrando interés, preguntas relevantes, y un uso adecuado de dispositivos electrónicos. Los grupos evaluarán a sus integrantes en: participación, actitud, responsabilidad, resolución de conflictos, uso del tiempo, comportamiento, y respeto a opiniones. No se aceptan proyectos individuales.

**Deberes.** Incluyen tareas individuales y grupales. Entregas tardías tienen penalización del 50% si se entregan un día después. Asegúrate de compartir correctamente los enlaces; links sin acceso serán penalizados con el 50% de la nota.

**Proyecto Final.** Desarrolla una solución analítica visual para problemas empresariales. El proyecto debe incluir: extracción, limpieza y modelamiento de datos, además de visualizaciones claras y efectivas. La evaluación incluirá propuesta, pitch, y visualización final.

**Evaluaciones y Certificaciones.** Este apartado incluye exámenes, evaluaciones, y certificaciones. Cada estudiante debe activar su cuenta en DataCamp con el correo institucional y completar los desafíos, cursos y talleres asignados en D2L. Las fechas de entrega serán las indicadas en D2L. Puedes inscribirte en otros cursos adicionales para obtener más certificados.

## Políticas específicas del curso

**Conexión desde computadora.** Es requisito obligatorio conectarse a las clases desde una computadora (laptop o escritorio). El uso de celulares o tablets no está permitido, ya que realizaremos ejercicios prácticos simultáneos en KNIME/Python que requieren capacidad de procesamiento y multitarea.

**Uso de cámara.** Para fomentar un entorno de aprendizaje humano y transparente, todos los estudiantes deben mantener su cámara encendida durante toda la sesión. Si tienes algún inconveniente técnico puntual, deberás informarlo al inicio de la clase.

**Trabajo en equipo.** Gran parte de la dinámica del curso se basará en breakout rooms (salas de grupos). Se espera una participación activa y colaborativa. El no interactuar con tu equipo afectará la nota de participación y el progreso de tus proyectos.

**Entorno profesional.** Al ser una clase en vivo, asegúrate de estar en un lugar tranquilo, con buena conexión a internet y micrófono funcional para poder intervenir cuando la clase lo requiera.

## Cronograma de actividades

| Semana | Tema Principal | Enfoque Técnico (Nodos y Herramientas) |
|---|---|---|
| 1 | Introducción a Business Analytics y Big Data | Instalación de KNIME Analytics Platform y extensiones |
| 2 | Business Analytics en las organizaciones | Interfaz de KNIME: Nodes, Workflows y Node Repository |
| 3 | Estadística descriptiva con KNIME | Nodos: Statistics, Color Manager y exploración visual inicial |
| 4 | Manipulación de datos (el "Pandas" de KNIME) | Nodos de ETL: Row Filter, Column Filter, Joiner, Concatenate |
| 5 | Transformación avanzada y limpieza de datos | Nodos: GroupBy, Pivoting, Missing Value y Rule Engine |
| 6 | Visualización de datos con KNIME | Nodos de visualización dinámica: Bar Chart, Scatter Plot, Pie Chart |
| 7 | Visualización avanzada y dashboards | Creación de Components y uso de Interactive View para reportes |
| 8 | TI y aplicaciones de negocio / Modelos analíticos | Gestión de flujos de trabajo y lectura de bases de datos (DB Connectors) |
| 9 | Modelos analíticos / Regresión lineal y múltiple | Nodos: Linear Regression Learner y Regression Predictor |
| 10 | Regresión aplicada | Evaluación de modelos: Numeric Scorer y análisis de residuos |
| 11 | Introducción a la minería de datos | Segmentación con Clustering: nodos K-Means y Color Manager |
| 12 | Minería avanzada y construcción de KPIs | Automatización de reportes y creación de métricas de negocio |
| 13 | Dashboards complejos y Machine Learning | Nodos: Decision Tree Learner y Random Forest |
| 14 | Machine Learning aplicado a los negocios | Validación cruzada (Cross-Validation) y curvas ROC |
| 15 | Híbrido: de KNIME a Python con IA | Uso del nodo Python Script y el asistente K-AI para generar código |
| 16 | Cierre del curso y presentación final | Entrega del proyecto integrador (workflow documentado) |
