## Enunciado original

En un nuevo cuaderno de python, crea un sistema bancario simple en Python que permita a los usuarios realizar las siguientes operaciones:

Crear una nueva cuenta bancaria con un balance inicial.

Depositar dinero en una cuenta bancaria.

Transferir dinero entre cuentas bancarias.

Requisitos:

Utiliza un diccionario para almacenar las cuentas bancarias, donde la clave es un identificador único de la cuenta (por ejemplo, un número de cuenta o el nombre del titular) y el valor es el balance actual de la cuenta.

Utiliza listas para almacenar las transacciones realizadas, cada transacción es un diccionario.

Deberías poder ejecutar estas funciones:

crear_cuenta('001', 1000) 

crear_cuenta('002', 500) 

depositar('001', 500) 

transferir('001', '002', 200)
